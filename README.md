# Power-analysis experiments on SQIsign 3.0: ideal intersection and equivalent prime ideal

Firmware, host tools, label data, analysis scripts and figure sources for the
two leakage-extraction experiments of **Section 5.2** of the paper
(*leakage extraction for the sublattice attack of Section 3.2*):

| Folder | Paper | Target routine (SQIsign 3.0 reference code) |
|---|---|---|
| [`5.2.1_intersection/`](5.2.1_intersection/) | §5.2.1, Fig. 2, Table 4, Listing 1 | `quat_ideal_intersect_O0` (**Intersect**) |
| [`5.2.2_equivalent_prime_ideal/`](5.2.2_equivalent_prime_ideal/) | §5.2.2, Fig. 3, Table 5, Listing 2 | `quat_ideal_create_O0_inert_odd`, the tail of **EquivalentCoprimeIdeal** |
| [`common/`](common/) | §5.2 setup | ChipWhisperer firmware project, SQIsign source patches, capture scripts |

Everything here concerns **Round-3 SQIsign** (`nist-v3`, commit
[`6d01770`](https://github.com/SQIsign/the-sqisign/commit/6d017708db403bf83977fa70770fc4f7f9e9ff21),
variant `p324_3`). Raw power traces (about 3 GB) are not part of the repository;
the files needed to re-acquire them (firmware sources, the exact input streams, the
labels) and the derived results they produced (guessing-entropy curves, figures)
are.

## Experimental setup (as in the paper)

* **Device.** STM32F303 (ARM Cortex-M4) on a ChipWhisperer-Lite Arm board,
  target clock 7.37 MHz, ADC synchronous at 4 samples per clock (≈ 29.5 MS/s),
  gain 30 (≈ 24.8 dB). A GPIO trigger brackets the traced region; traces are
  captured at a fixed offset, no re-alignment.
* **Design.** 21,000 traces per configuration in a fixed-versus-random design on
  the *secret*: 18,000 records use a freshly sampled secret ideal (profiling set)
  and 3,000 reuse one fixed secret ideal (attack set). The public operands
  (`a`, `split_a`) are fixed and compiled into the firmware (`common/firmware/fixed_as.h`).
* **Software.** The device runs the unmodified arithmetic of the reference
  implementation; the only modifications are trigger and label-dump hooks
  (`common/firmware/patches/0001-*`) and, for the 16-bit-limb builds, the
  `RADIX_16` build support (`0002-*`, `0003-*`).
* **Metrics.** Within-Hamming-weight value-SNR with a label-permutation null,
  CPA-style |r|, and leave-one-value-out guessing entropy (GE) with bit-linear
  (stochastic) templates averaged over all 256 byte values. Definitions are in
  the paper; the implementation is `*/analysis/recovery_ge*.py`.

## Layout

```
common/
  firmware/            CW SimpleSerial-2.1 firmware project (Makefile, harness headers)
    get_sqisign.sh     fetches the-sqisign@6d01770 and applies the patches  -> ./sqisign/{src,inc}
    sqisign_files.lst  the 18 C files + headers of the quaternion/mp layer that are used
    patches/0001..0003 trigger/dump hooks; RADIX_8/16 build support; radix-portable div/invmod
    tvla_io.h          wire format of one serialized ibz_t / record (host <-> device)
    tvla_core_rk.h     the traced call quat_ideal_intersect_O0(out, a_fixed, b, split_fixed)
    fixed_as.h         the fixed public operands (regenerated by 5.2.1/host/tvla_gen_rk)
    host_rng.c         deterministic PRNG backend for the host generators
  host/
    capture_chunked.py USB-resilient chunked capture (21,000-trace runs; parts carry kept_idx)
    capture_single.py  single-file capture with ADC decimation / stepped segments (window scans)
    concat_parts.py    merge the chunk parts of a run into one .npz
5.2.1_intersection/    firmware/ host/ data/ analysis/ results/   (see its README)
5.2.2_equivalent_prime_ideal/                                        (see its README)
```

## Reproducing

### 1. Sources

```bash
cd common/firmware && ./get_sqisign.sh            # + 0001, 0002
# ./get_sqisign.sh --with-radix16-mp              # also 0003 (host-side full Intersect at RADIX_16)
```

### 2. Host tools, inputs and labels (x86, gcc)

```bash
cd 5.2.1_intersection/host && ./build_host.sh
cd ../data && ../host/bin/tvla_gen_rk 21000 7     # fixed_as.h, tvla_inputs_rk.bin, classes, CRCs
../host/bin/gauss_host                            # gauss_inputs_rk.bin + gauss_bx0_rk.bin   (W1)
../host/bin/outlabel_host                         # x2_*_low4.bin, y2_low4.bin, out_*_low4.bin (W2, W3)
cd ../../5.2.2_equivalent_prime_ideal/host && ./build_host.sh
cd ../data && ../host/bin/equiv_host ../../5.2.1_intersection/data/tvla_inputs_rk.bin tvla_inputs_equiv.bin
python ../host/make_prime_inputs.py tvla_inputs_equiv.bin tvla_inputs_prime.bin
```

All of these regenerate the shipped `data/` files byte for byte (the generators
are deterministic: `host_rng.c` plus `srand(7)` for the class interleave).

### 3. Firmware (ChipWhisperer build system, arm-none-eabi-gcc)

Check the repository out under `chipwhisperer/firmware/mcu/` (or pass
`CWFIRMWARE=/path/to/chipwhisperer/firmware/mcu`) and build from
`common/firmware`; the variant table is in `common/firmware/Makefile` and in
each experiment's README. Example:

```bash
cd common/firmware
make TARGET=sqisign-equiv-r32 TVLA_TARGET_SRC=equiv_target.c TVLA_DEFS=-DTVLA_TRIG_EQUIVREGION \
     RADIX=RADIX_32 PLATFORM=CWLITEARM CRYPTO_TARGET=NONE SS_VER=SS_VER_2_1        # -Os
make OPT=0 TARGET=sqisign-equiv-r32-o0 ... (same variables)                        # -O0
```

### 4. Capture

```bash
cd <data dir>   # the folder holding the *.bin inputs/labels; traces are written next to them
python ../../common/host/capture_chunked.py --inputs tvla_inputs_equiv.bin \
       --hex sqisign-equiv-r32-CWLITEARM.hex --outprefix traces_equivos --samples 8000 --adc-x 4 --gain 30
python ../../common/host/concat_parts.py traces_equivos
```

`capture_chunked.py` streams each record over SimpleSerial 2.1, arms the scope,
records the trace between the trigger edges and saves 3,000-trace parts that
carry the global record index (`kept_idx`) for label alignment. Window scans
(decimated or stepped captures) use `capture_single.py`.

### 5. Analysis

Each `analysis/` script reads labels and traces from one directory,
`$SQI_DATA` (default: the experiment's `data/`), writes JSON results to
`results/`, and the `make_*_figure.py` scripts turn those JSON files into the
PGFPlots/PDF figures used in the paper. The figure scripts run without traces.
